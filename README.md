# Pattern Spotter

A small web app for learning LeetCode patterns: lessons, quizzes, and block builders for the 75 problems in the course list.

Open `index.html` in a browser, or host it on GitHub Pages (see below). Progress is saved in the browser you use.

## Deploy to GitHub Pages

1. Create a new repository on GitHub named `pattern-spotter` (public is fine).
2. Upload `index.html` and `README.md` to the repository root (Add file > Upload files > Commit changes).
3. Go to Settings > Pages.
4. Under "Build and deployment", set Source to "Deploy from a branch", Branch to `main`, folder `/ (root)`, then Save.
5. After a minute, the site is live at `https://<your-username>.github.io/pattern-spotter/`.
